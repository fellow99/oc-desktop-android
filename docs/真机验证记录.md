### 关键发现（新）

1. **x86_64 模拟器可跑 arm64 引擎**：API 37 模拟器带 arm64 转译，`dlopen('libnode.so')` + `node::Start` 全链路可用（arch=arm64）。真机性能待复测。
2. **监听 socket 泄漏**：进程被杀后其 `127.0.0.1` LISTEN socket 在内核残留（后续 bind 同端口报 EADDRINUSE，队列积压连接无人 accept）。⇒ 印证 D3「产品路径必须 `--port 0`」；探针侧已改 port 0 + ready 文件。
3. **debug manifest 相对类名**：`<activity android:name=".probe.X">` 会被改写到 applicationId 包下 ⇒ 必须写全限定类名。

### 关键发现（新）

1. **AGP 会把 assets 里 `*.tar.gz` 预解压为裸 `*.tar`**（merger 实测）：Kotlin 端双名探测（`.tar.gz`→`.tar`），Node 端 `1f 8b` 魔数判定 gzip/裸 tar。
2. **凭据迁移须在 DB 首建前**：auth.json 的 legacy 导入只发生在 DB 初始化；运行期写入应走 `/api/credential`（UI 同路径），本轮按后者验证。
3. 模拟器上 bundle import + 首个模型请求全链路耗时约 40s（转译环境），真机预期显著更快。
4. `git-bash` 下 adb push 需 `MSYS_NO_PATHCONV=1` 防路径改写（工程纪要，不影响交付物）。

   **纪律**：payload 新增文件必须同时改 `syncPayloadScripts`（gradle 通配已含）与
   `OpencodeRuntime.ensurePayload` 白名单两处。
2. **switchModel 的 Model.Ref 字段名是 `id`**（非 `modelID`）：`{"model":{"providerID":"deepseek","id":"deepseek-flash"}}`。

   录入 provider 凭据并显式 switchModel 后正常；与上轮「/api/config 默认模型」行为差异源于全新 DB。
4. 消息列表形状：`{data:[{type:"assistant",model,content:[{type:"text",text}],finish}]}`（顶层字段，非嵌套 info）。
