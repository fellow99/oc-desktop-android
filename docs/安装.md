# G8 侧载安装文档（OC Desktop Android v2.1.2）

## 前置要求

- Android 7.0（API 24）及以上，**arm64-v8a** 设备（平板/折叠屏/桌面窗口优先）
- 可用存储 ≥ 2GB（APK ≈ 121–156MB，安装后解包载荷 ≈ 80–110MB + 运行数据）
- 模型服务的 API Key（如 DeepSeek）

## 安装步骤

1. 将 `app-release.apk` 传输到设备（USB / 网盘 / 局域网共享均可）。
2. 在文件管理器中点击 APK → 系统提示「未知来源」→ 允许该来源安装（各 ROM 入口不同，
   小米/MIUI：「设置 → 更多设置 → 开发者选项 → USB 安装」需开启；华为/荣耀：「纯净模式」需关闭）。
3. 完成安装后启动 **OC Desktop Android**。
4. 首次启动依次经历：准备载荷 → 启动服务 → 连接界面（首启约 30–60s，二次启动更快）。
5. 进入 Web 界面后：设置 → Providers → DeepSeek → 填入 API Key；模型选 `deepseek-flash`。
6. （可选）工作区：界面内工作区选择器 → 沙箱 → 新建/导入（SAF 选目录会拷入应用沙箱，原目录不受影响）。
7. （可选）保活：应用内「返回 → 退出对话框 → 关于 → 保活: 关（点击开启）」→ 长会话后台保活
   （Android 13+ 会请求通知权限）。

## 已知限制（如实告知）

- 无终端/PTY、`rg`/`fff` 原生搜索不可用（JS 兜底已内置）
- `pnpm run`/生命周期脚本不可用（设备无 node 可执行体；依赖安装不受影响）
- MCP 仅 HTTP/SSE 形态（stdio 形态依赖外部 node，不可用）
- 进程内 Node 崩溃 = 应用崩溃（终态），错误页提供「重启应用」
- 定制 ROM 的「USB 安装」限制、后台查杀策略差异见上表第 2 步

## 卸载

系统设置 → 应用 → OC Desktop Android → 卸载（会话/凭据/工作区随沙箱一并清除）。
